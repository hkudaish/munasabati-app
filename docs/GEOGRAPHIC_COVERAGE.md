# إدارة التغطية الجغرافية

المسار `/system-admin/geography` متاح فقط لحساب `SUPER_ADMIN`، ومستقل عن لوحة الإدارة المعتادة. الدول والمناطق والمدن وقواعد إتاحة الخدمات محفوظة في PostgreSQL، ويقرأ الخادم والواجهة القواعد نفسها.

## التثبيت والترقية

على قاعدة موجودة طبّق `prisma/sql/20261017-geographic-coverage.sql` بعد نسخها احتياطياً، ثم شغّل `npx prisma generate`. الترحيل إضافي ويحافظ على معرفات المدن وحالاتها والطلبات السابقة؛ لا تستخدم إعادة ضبط قاعدة البيانات. على قاعدة جديدة يمكن تطبيق مخطط Prisma ثم تشغيل `node scripts/seed-geography.cjs` بعد استيراد المدن والخدمات الأساسية.

## عمل المدير

1. أضف دولة ومدينة، أو راجع نتائج GeoNames قبل استيرادها، أو ارفع CSV بترميز UTF-8. يمكن حفظ جدول Excel بصيغة CSV؛ ملفات XLSX الثنائية غير مدعومة. المدن والدول الجديدة غير مفعّلة تلقائياً.
2. اختر المدن والخدمات الموجودة فعلياً، واضبط التفعيل أو التعطيل أو المواعيد والرسالة التي يراها الزائر. الإتاحة الافتراضية تخص الخدمات التي لا تملك قاعدة صريحة. نسخ مدينة ينقل قواعدها وإتاحتها الافتراضية.
3. احفظ المسودة وراجع مقارنة التغييرات وعدد الطلبات السابقة المتأثرة من حيث النطاق. اختبر معاينة المدينة على الهاتف والحاسوب، ثم انشر. المسودات خاصة بصاحبها ولا تغيّر الموقع العام. عند تعارض إصدار الإعدادات يجب إعادة تأسيس المسودة ومراجعتها.

التعطيل العام للخدمة أو المورد يتقدم على التغطية المحلية. ثم يطبّق تفعيل الدولة والمدينة، وقاعدة الخدمة ووقتها، ثم الإتاحة الافتراضية. تغيير التغطية يمنع الطلبات الجديدة غير المتاحة، ولا يلغي الطلبات السابقة أو يمنع قراءة حجوزاتها أو تأكيد حضور الدعوات السابقة.

## اختيار الموقع والخصوصية

الاختيار اليدوي له الأولوية ويحفظ في قاعدة البيانات مع معرف جلسة عشوائي داخل ملف تعريف ارتباط HttpOnly؛ لا يعتمد على localStorage. عدم معرفة المدينة يعرض طلب اختيار واضحاً ولا يفترض الرياض.

تحديد الموقع الدقيق يحتاج نقرة وموافقة صريحة من الزائر وتفعيل السياسة ومفتاح `GEOAPIFY_API_KEY` على الخادم. لا يرسل المفتاح للمتصفح ولا تحفظ الإحداثيات. عند غياب المفتاح يبقى الاختيار اليدوي متاحاً. الموقع التقريبي عبر IP يقبل فقط رؤوس الموقع الموثوقة عند التشغيل على Vercel؛ لا يثق برؤوس يرسلها العميل على الخادم المحلي، ولا يحفظ عنوان IP.

التحليلات معطّلة افتراضياً. عند تفعيلها تسجل الزيارات ومحاولات الطلب والمنع الفعلية كإحصاءات مجمعة مع منع تكرار الزيارة اليومية للجلسة. تعرض اللوحة إجماليات آخر 30 يوماً وأعلى المدن والخدمات، وتقتصر قائمة التفاصيل على آخر 1000 سجل. هذه الأرقام ليست إحصاءً فريداً للأشخاص عبر الأجهزة.

## المعاينة

رابط `/coverage-preview/...` خاص بمدير النظام الذي أنشأه وينتهي بعد ساعتين. يستخدم الموقع الفعلي وقواعد التغطية المنشورة أو المسودة مع زائر اصطناعي، ويمنع عمليات الكتابة عبر وكيل API مخصص. نوع الزائر في المعاينة صفة عرض فقط ولا يمنح اشتراكاً أو صلاحيات أو حساباً حقيقياً. لا تعدّل المعاينة مدينة المدير الأصلية ولا تولّد زيارات تحليلية.

## المصادر والحدود

الكتالوج الاختياري من [GeoNames](https://www.geonames.org/) و[ملفات التنزيل](https://download.geonames.org/export/dump/) وفق [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). يعرض حتى 300 تجمع سكاني يتجاوز 5000 نسمة لكل دولة، وليس سجلاً شاملاً لكل القرى. يمكن إضافة المدن الأخرى يدوياً أو عبر CSV. يحتفظ الاستيراد بالمعرف الخارجي والأسماء البديلة، ويطابق المدينة القديمة عند وجود تطابق وحيد آمن لتجنب تغيير معرفها. تحديد المدينة من الإحداثيات يستخدم [Geoapify](https://www.geoapify.com/).

## التحقق

`npm run test:geo-engine` يختبر أولوية القواعد والمواعيد والأسماء البديلة وCSV. `npm run test:geography` يتطلب بناء النسخة الإنتاجية أولاً عبر `npm run build`، ثم ينشئ مخطط PostgreSQL مؤقتاً وخادماً إنتاجياً على المنفذ 3101، ويختبر الصلاحيات والمسودات والنشر والتعارض والاستيراد والطلبات السابقة والتحليلات والمعاينة، ثم يختبر الواجهة بمتصفح Chrome أو Edge محلي. يحذف مخطط الاختبار بعد الانتهاء ويحفظ لقطات الواجهة في `.geo-test-artifacts/`. يحتاج فحص المتصفح Node حديثاً يدعم WebSocket، ويستخدم ملف متصفح مؤقتاً.
