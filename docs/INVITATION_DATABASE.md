# الدعوات وقنوات الإرسال — التشغيل والحفظ

أصبحت PostgreSQL عبر Prisma مصدر بيانات المناسبات والضيوف والردود وتخصيص الطاولة لكل ضيف ومسودات البطاقات والقوالب المرفوعة والمفضلة وإعدادات القنوات وسجل محاولات الإرسال. لا تستخدم هذه المسارات بيانات تجريبية عند فشل قاعدة البيانات، ولا تعرض نجاح الحفظ قبل تأكيد الخادم. بيانات التجارة والميزانية والمهام وبقية أجزاء التطبيق التجريبية ليست ضمن هذا النقل، وما زالت تستخدم مخزنها السابق.

## قاعدة البيانات

- للمشروع الحالي قبل هذا التحديث، نفّذ مرة واحدة بعد أخذ نسخة احتياطية:
  `npx prisma db execute --schema prisma/schema.prisma --file prisma/sql/20261016-invitation-persistence.sql`
- الترحيل إضافي داخل معاملة واحدة: لا يحذف جداول أو بيانات. نُفّذ على قاعدة التطوير الحالية. لا تعاود تشغيله على قاعدة سبق تحديثها.
- لقاعدة جديدة فارغة: `npx prisma db push` ثم تهيئة المدن/التصنيفات بوسيلة المشروع المعتادة. لا تعِد تشغيل سكربت البذر على قاعدة مستخدمة قبل مراجعة أثره.
- بعد تحديث المخطط: `npx prisma generate` ثم أعد تشغيل التطبيق. ملف SQL مستقل؛ لا يفترض وجود سجل سابق لـ Prisma Migrate.
- شغّل PostgreSQL على تخزين دائم، واتصال TLS عند استخدام قاعدة بعيدة، ونسخ احتياطي آلي مع اختبار الاستعادة. هذا التحديث لا ينشئ خدمة نسخ احتياطي أو استضافة سحابية.

## الجلسات وكلمات المرور

توقّف تسجيل الدخول التجريبي الذي كان يقبل رقمًا أو دورًا دون كلمة مرور. التسجيل الجديد يحفظ تجزئة scrypt بملح عشوائي. الجلسة ذات رمز عشوائي محفوظ كتجزئة في قاعدة البيانات، وملف ارتباط HttpOnly وSameSite=Lax، وSecure في الإنتاج. يتحقق الخادم من المالك والدور من قاعدة البيانات؛ لا يثق بدور أو معرف حساب من المتصفح. تسجيل الخروج يلغي الجلسة على الخادم. الحسابات القديمة ذات كلمة المرور الفارغة لا تستطيع الدخول حتى يهيئها المشغل.

لتهيئة كلمة مرور حساب قائم، مرر `ACCOUNT_IDENTIFIER` و`ACCOUNT_PASSWORD` إلى عملية محلية موثوقة ثم شغّل:

```sh
node --env-file=.env scripts/set-account-password.cjs
```

تُقرأ كلمة المرور من البيئة ولا تُطبع. استخدم كلمة من 12–128 حرفًا، ولا تحفظها في المستودع أو سجل أوامر مشترك. السكربت لا ينشئ حسابًا ولا يغيّر الدور، ويلغي جلسات الحساب السابقة. لا توجد واجهة عامة تسمح بالاستيلاء على حساب قديم. لم تُضف بعد دورة استعادة ذاتية لكلمة المرور أو تحقق ملكية رقم الهاتف.

## نقل النسخة السابقة

افتح `/settings/invitations-data` بعد الدخول. عند وجود بيانات مناسبات وضيوف قديمة في مخزن التطبيق، يحتفظ التطبيق بنسخة ترحيل مستقلة ولا يستخدمها كمصدر حي. اختر مناسبتك وأكد ملكيتها لنقلها في معاملة واحدة. تكرار استيراد المناسبة للحساب نفسه لا يكرر الضيوف. المعرفات والروابط الجديدة عشوائية، ولا يتم تعيين ملكية صفوف قديمة لحساب آخر. مسودات وقوالب المحرر القديمة ما زالت في مفاتيحها السابقة؛ يمكن نقل القوالب من ملفات JSON عبر واجهة الاستيراد. لا تُستورد صلاحيات النشر أو هوية المالك من ملفات القوالب.

الروابط القديمة ذات `#inv` والأكواد التجريبية لا تُعتبر مصدرًا موثوقًا ولا تقبلها واجهة RSVP. للضيوف القدامى في قاعدة البيانات، يمكن للمالك تجديد الرابط من قائمة الضيوف ثم إعادة مشاركته.

## تأكيد الحضور والبوابة

الرابط الشخصي يحمل رمزًا عشوائيًا بطول 43 حرفًا (32 بايت). يقرأ الضيف تفاصيل المناسبة العامة واسمه وعدد المرافقين المسموح به فقط، دون هاتف أو بريد أو ميزانية. يحفظ الرد والتهنئة وعدد المرافقين المؤكد في قاعدة البيانات. رابط المناسبة العام يعرض التفاصيل ولا يسمح بتأكيد ضيف مجهول. تُرفض الدعوة الملغاة، والردود بعد دخول البوابة، وعدد المرافقين الذي يتجاوز المسموح.

تسجيل دخول البوابة عملية شرطية ذرية: لا تنجح عمليتا إدخال للضيف نفسه. تعرض لوحة المنظم آخر بيانات الخادم كل 10 ثوانٍ وعند التركيز على النافذة. القارئ الحالي يقبل لصق رمز أو رابط؛ لا يضيف هذا التحديث ماسح كاميرا. إبطال الرابط أو تجديده متاحان من إجراءات قنوات الضيف.

المسودات والقوالب تستخدم رقم إصدار لمنع الكتابة فوق تعديل جهاز آخر، والمراجعة والنشر يتطلبان دور إدارة في قاعدة البيانات. الصور المضمنة مقيدة بالنوع والحجم والتحقق الحالي للتصميم؛ لم تُضف خدمة ملفات أو فحص صور مستقل.

## إعدادات القنوات

افتح `/settings/channels` من قائمة الحساب أو محرر الدعوة. كل حساب يملك إعداداته الخاصة. المفاتيح مشفرة بـAES-256-GCM مع ربطها بالحساب والقناة. لا ترجع واجهة القراءة النص المشفر أو المفتاح؛ ترجع `hasSecret` فقط. ترك خانة المفتاح فارغة يبقي المفتاح الحالي؛ حذف الربط يحذفه من قاعدة البيانات.

ضع `CHANNEL_ENCRYPTION_KEY` في بيئة الخادم: 64 خانة hexadecimal عشوائية، دون بادئة NEXT_PUBLIC. تم إنشاء مفتاح للتطوير في ملف `.env` المستثنى من Git. احتفظ بالمفتاح ضمن النسخ الاحتياطي للأسرار؛ فقدانه يمنع فك إعدادات القنوات. لا تغيّره دون إعادة تشفير السجلات. اضبط `NEXT_PUBLIC_APP_URL` على عنوان HTTPS المنشور قبل الإرسال في الإنتاج.

المزودون المنفذون:

- واتساب: [Meta Cloud API](https://www.postman.com/meta/whatsapp-business-platform/documentation/wlk6lh4/whatsapp-cloud-api). يلزم Access Token ومعرف رقم الهاتف وإصدار API واسم ولغة قالب معتمد. قالب الجسم يتوقع ثلاثة متغيرات نصية بالترتيب: اسم الضيف، عنوان المناسبة، رابط الدعوة. يلزم الالتزام بموافقة المستلم ومتطلبات حساب المزود.
- SMS: [Twilio Messages API](https://www.twilio.com/docs/messaging/api/message-resource). يلزم Account SID وAuth Token ورقم أو اسم مرسل مسموح والإرسال إلى بلد المستلم.
- البريد: [Resend Send Email](https://resend.com/docs/api-reference/emails/send-email). يلزم API Key وبريد مرسل من نطاق متحقق منه.

القنوات معطلة افتراضياً. حفظ الإعدادات لا يرسل رسالة. الإرسال عملية صريحة من قائمة الضيوف؛ البريد يتطلب إدخال بريد الضيف عند إضافته. تُسجل المحاولات في قاعدة البيانات. `ACCEPTED` يعني قبول المزود، وليس إثبات وصول للمستلم. `UNKNOWN` أو `PENDING` لا يعاد إرسالهما آليًا؛ راجع لوحة المزود قبل بدء طلب جديد. مفتاح الطلب الفريد يمنع إعادة إرسال الطلب نفسه، ويُمرر أيضًا إلى Resend. لم تُضف webhooks لتحديث حالات التسليم، ولا طابور عامل خارجي لإعادة المحاولة. لا تعيد الخدمة محاولة الإرسال تلقائياً بعد انقطاع الاتصال، لتقليل خطر التكرار.

## التحقق

```sh
npm run test:invitations
npm run test:channels
# يتطلب خادم التطبيق وقاعدة تطوير تعمل؛ ينشئ حسابات مؤقتة ويحذفها بعد الاختبار.
npm run test:invitation-db
npx tsc --noEmit --incremental false
npm run lint
npm run build
```

اختبار المزودين يستخدم fetch محاكاة ولا يرسل رسائل. اختبار التكامل يفحص عزل الحسابات وCSRF والخصوصية وحفظ RSVP من جلسة ضيف دون دخول وظهوره للمنظم وحد المرافقين والدخول المتزامن وتعارض المسودات وصلاحيات القوالب والتشفير والاستيراد المتكرر ومنع إعادة إرسال الطلب المسجل وإلغاء الجلسات. لا يُثبت ذلك صلاحية بيانات مزود حقيقية لم تُدخل بعد، ولا تسليم رسائل فعلية.
