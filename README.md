# مناسبتـي | Munasabati 🇸🇦
### المنصة الرقمية السعودية المتكاملة لتخطيط وإدارة المناسبات وحجز الخدمات والاحتفالات
> **"خطّط. احجز. اعزم. واحتفل."**

---

## 🌟 نظرة عامة
تطبيق ويب متطور ومتجاوب (Mobile-First / Arabic-First) مصمم خصيصاً للثقافة السعودية لتسهيل تخطيط وإدارة جميع المناسبات (أعراس، ملكة، غمرة، تخرج، استقبال مواليد، أعياد، اجتماعات شركات، يوم تأسيس، ويوم وطني) عبر 10 مدن رئيسية في المملكة.

---

## ✨ المميزات الرئيسية

1. **مساحة عمل المناسبة المركزية (Occasion Workspace)**:
   - إدارة الضيوف والتأكيدات الذكية (RSVP) وحالات الحضور.
   - مخطط توزيع الطاولات والقاعات التفاعلي (Table & Seating Planner).
   - إدارة الميزانية مع حساب ضريبة القيمة المضافة 15% وتتبع المصاريف والمدفوعات.
   - مولد بطاقات الدعوة الرقمية الفاخرة مع باركود QR فريد وميزة المشاركة عبر واتساب.
   - جدول المهام الزمني (Timeline) وقوائم الهدايا التشاركية (Gift Wishlist).

2. **المخططة الذكية "لُـمى" (AI Event Planner)**:
   - مساعدة ذكية تفهم اللهجات والمناسبات السعودية، تقترح باقات وخدمات وميزانيات تقديرية وتنشئ خطة متكاملة بضغطة زر.

3. **سوق الخدمات والموردين (Saudi Vendors Marketplace)**:
   - تصنيفات مخصصة: قاعات ومخيمات، كوش وتنسيق، ضيافة وقهوجيين وصبابين، بوفيه وذبائح، تصوير وموسيقى وعرضة سعودية.
   - فلترة حسب 10 مدن سعودية، وتوثيق السجل التجاري وشهادة العمل الحر.

4. **الباقات الذكية الشاملة (Curated Smart Packages)**:
   - باقات متكاملة قابلة للتخصيص (إضافة/حذف عناصر وحساب السعر الإجمالي فورياً).

5. **نظام طلب ومقارنة عروض الأسعار (RFQ & Comparison Matrix)**:
   - إرسال طلبات عروض أسعار للموردين مع جدول مقارنة تفاعلي جنبًا إلى جنب لاختيار الأنسب.

6. **بوابة الدخول السريع بالباركود (`/scan`)**:
   - ماسح ضوئي ذكي لبوابات المناسبات يقرأ رمز QR للدعوة، يتحقق من الحضور، ويسجل الدخول بضغطة واحدة.

7. **أنظمة الدفع السعودية المتوافقة**:
   - دعم مدى (Mada)، Apple Pay، STC Pay، وتابي/تمارا، مع خيار دفع العربون 30% أو المبلغ كاملاً، وإصدار الفاتورة الضريبية المعتمدة.

8. **بوابة الموردين (`/vendor`) ولوحة تحكم الإدارة (`/admin`)**:
   - لوحات تحكم متقدمة لإدارة الحجوزات والتحقق من التراخيص وتتبع إجمالي حجم التعاملات (GMV).

## 🚀 التشغيل والتطوير المحلي

```bash

# بناء النسخة الإنتاجية
npm run build

# تشغيل النسخة الإنتاجية
npm run start
```
